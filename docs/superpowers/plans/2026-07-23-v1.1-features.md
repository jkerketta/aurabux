# v1.1 Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add friend portfolio viewing, achievements, spin streaks, watchlist, and net worth history graph to Aurabux v1.1.

**Architecture:** Three new DB tables (`user_achievements`, `watchlist`, `portfolio_snapshots`) + two shared libs (`achievements.ts`, `streak.ts`) + new API endpoints under `/api/friends/[id]/portfolio`, `/api/achievements`, `/api/watchlist`, `/api/portfolio/snapshots`. UI uses existing slide-up sheet pattern (FriendsModal) for friend view + achievements sheet + net worth sheet. Watchlist lives on search page empty state + stock detail star toggle. Streak badge emerges inside existing SpinModal. Bklit UI line chart extends the existing charts directory for the net worth graph.

**Tech Stack:** Next.js 15 App Router, Supabase (Postgres + RLS + service role), Tailwind v4, Bklit UI (@bklit/line-chart), framer-motion (sheets), sonner (achievement toasts).

## Global Constraints

- Follow existing shadcn/ui patterns (new-york style, zinc base)
- Server components by default; `"use client"` only for interactivity
- Service role (`createAdminClient()`) only for: friend portfolio reads, achievement unlocks, snapshot upserts — never for user-writable data
- All DB tables get RLS; user-writable tables (watchlist) get full owner CRUD policies
- Verify each task with `node ./node_modules/typescript/bin/tsc --noEmit` (WSL environment — `npm run build` has filesystem boundary issues)
- Commit after each task with conventional commits
- No test framework configured — verification is TypeScript compile + manual review

## Build Order

1. **DB migrations** (3 tasks) — tables must exist before any feature code references them
2. **Shared libs** (2 tasks) — `streak.ts` + `achievements.ts` provide logic consumed by API routes and UI
3. **Streak feature** (1 task) — smallest, reacts with existing spin flow
4. **Achievements feature** (3 tasks) — evaluation hooks + API + UI sheet
5. **Friend portfolio view** (2 tasks) — API endpoint + sheet UI
6. **Watchlist feature** (3 tasks) — API + search page + stock detail star
7. **Net worth graph** (3 tasks) — Bklit line chart install + snapshot upsert + API + sheet

### Task 4: Streak library (`src/lib/streak.ts`)

**Files:**
- Create: `src/lib/streak.ts`

**Interfaces:**
- Produces:
  - `getCurrentStreak(supabase: SupabaseClient, userId: string): Promise<number>` — returns consecutive-day count ending today/yesterday
  - `getStreakBonus(streak: number): number` — returns multiplier `Math.min(1 + streak * 0.10, 1.70)`

- [ ] **Step 1: Write the streak library**

```ts
import type { SupabaseClient } from "@supabase/supabase-js";

function isSameOrAdjacentDay(prev: Date, curr: Date): boolean {
  const diffMs = curr.getTime() - prev.getTime();
  const dayMs = 24 * 60 * 60 * 1000;
  return diffMs >= 0 && diffMs < dayMs * 2;
}

function sameCalendarDay(a: Date, b: Date): boolean {
  return a.getFullYear() === b.getFullYear() &&
    a.getMonth() === b.getMonth() &&
    a.getDate() === b.getDate();
}

export async function getCurrentStreak(supabase: SupabaseClient, userId: string): Promise<number> {
  const { data } = await supabase
    .from("daily_spins")
    .select("created_at")
    .eq("user_id", userId)
    .order("created_at", { ascending: false })
    .limit(200);

  if (!data || data.length === 0) return 0;

  const spins = data.map((row: { created_at: string }) => new Date(row.created_at));
  const today = new Date();
  today.setHours(0, 0, 0, 0);

  // Most recent spin's calendar day
  let prevDay = new Date(spins[0]);
  prevDay.setHours(0, 0, 0, 0);

  // If most recent spin not today or yesterday, streak is 0
  if (!isSameOrAdjacentDay(prevDay, today)) return 0;

  let streak = 0;
  let lastSeen: Date | null = null;
  for (const spin of spins) {
    const day = new Date(spin);
    day.setHours(0, 0, 0, 0);
    if (lastSeen === null) {
      streak = 1;
      lastSeen = day;
      continue;
    }
    const diffDays = Math.round((lastSeen.getTime() - day.getTime()) / (24 * 60 * 60 * 1000));
    if (diffDays === 1) {
      streak += 1;
      lastSeen = day;
    } else if (diffDays === 0) {
      // Same day, skip duplicates
      continue;
    } else {
      break;
    }
  }

  return streak;
}

export function getStreakBonus(streak: number): number {
  if (streak <= 0) return 1;
  return Math.min(1 + streak * 0.10, 1.70);
}
```

```ts
async function getTxnCount(client: SupabaseClient, userId: string): Promise<number> {
  const { count } = await client.from("transactions").select("*", { count: "exact", head: true }).eq("user_id", userId);
  return count ?? 0;
}

async function getDistinctHoldingsCount(client: SupabaseClient, userId: string): Promise<number> {
  const { count } = await client.from("holdings").select("*", { count: "exact", head: true }).eq("user_id", userId);
  return count ?? 0;
}

async function getEarliestHoldingAgeDays(client: SupabaseClient, userId: string): Promise<number> {
  const { data } = await client.from("holdings").select("created_at").eq("user_id", userId).order("created_at", { ascending: true }).limit(1);
  if (!data || data.length === 0) return 0;
  const created = new Date(data[0].created_at);
  const diffMs = Date.now() - created.getTime();
  return Math.floor(diffMs / (24 * 60 * 60 * 1000));
}

async function getTotalInvested(client: SupabaseClient, userId: string): Promise<number> {
  const { data } = await client.from("portfolios").select("total_invested").eq("user_id", userId).single();
  return Number(data?.total_invested ?? 0);
}

async function getUnlockedKeys(client: SupabaseClient, userId: string): Promise<Set<string>> {
  const { data } = await client.from("user_achievements").select("achievement_key").eq("user_id", userId);
  return new Set((data ?? []).map((r: { achievement_key: string }) => r.achievement_key));
}

async function unlock(client: SupabaseClient, userId: string, keys: string[]): Promise<void> {
  if (keys.length === 0) return;
  const rows = keys.map((k) => ({ user_id: userId, achievement_key: k }));
  await client.from("user_achievements").upsert(rows, { onConflict: "user_id,achievement_key" });
}

export async function evaluateAchievements(
  adminClient: SupabaseClient,
  userId: string,
  context: { action: "buy" | "sell" | "spin"; portfolioTotalValue?: number }
): Promise<string[]> {
  const unlocked = await getUnlockedKeys(adminClient, userId);
  const newlyUnlocked: string[] = [];

  const txnCount = await getTxnCount(adminClient, userId);
  if (txnCount >= 1 && !unlocked.has("first_trade")) newlyUnlocked.push("first_trade");
  if (txnCount >= 10 && !unlocked.has("10_trades")) newlyUnlocked.push("10_trades");
  if (txnCount >= 100 && !unlocked.has("100_trades")) newlyUnlocked.push("100_trades");
  if (txnCount >= 1000 && !unlocked.has("1000_trades")) newlyUnlocked.push("1000_trades");

  const totalValue = context.portfolioTotalValue;
  if (totalValue !== undefined) {
    if (totalValue >= 15000 && !unlocked.has("net_worth_15k")) newlyUnlocked.push("15k");
    if (totalValue >= 25000 && !unlocked.has("net_worth_25k")) newlyUnlocked.push("25k");
    if (totalValue >= 50000 && !unlocked.has("net_worth_50k")) newlyUnlocked.push("net_worth_50k");
    if (totalValue >= 100000 && !unlocked.has("net_worth_100k")) newlyUnlocked.push("net_worth_100k");
    if (totalValue >= 250000 && !unlocked.has("net_worth_250k")) newlyUnlocked.push("net_worth_250k");
  }

  // Returns-based achievements (require holdings value + total_invested)
  const totalInvested = await getTotalInvested(adminClient, userId);
  if (totalInvested > 0 && totalValue !== undefined) {
    const pct = (totalValue - totalInvested) / totalInvested * 100;
    if (pct >= 10 && !unlocked.has("return_10pct")) newlyUnlocked.push("return_10pct");
    if (pct >= 25 && !unlocked.has("return_25pct")) newlyUnlocked.push("return_25pct");
    if (pct >= 50 && !unlocked.has("return_50pct")) newlyUnlocked.push("return_50pct");
    if (pct >= 100 && !unlocked.has("return_100pct")) newlyUnlocked.push("return_100pct");
  }

  // Spin streak achievements (only on spin action)
  if (context.action === "spin") {
    if (!unlocked.has("first_spin")) newlyUnlocked.push("first_spin");
    const streak = await getCurrentStreak(adminClient, userId);
    if (streak >= 3 && !unlocked.has("streak_3")) newlyUnlocked.push("streak_3");
    if (streak >= 7 && !unlocked.has("streak_7")) newlyUnlocked.push("streak_7");
    if (streak >= 30 && !unlocked.has("streak_30")) newlyUnlocked.push("streak_30");
    if (streak >= 100 && !unlocked.has("streak_100")) newlyUnlocked.push("streak_100");

  if (distinctCount >= 5 && !unlocked.has("5_distinct")) newlyUnlocked.push("5_distinct");
  const holdingAgeDays = await getEarliestHoldingAgeDays(adminClient, userId);
  if (holdingAgeDays >= 30 && !unlocked.has("hold_stock_30d")) newlyUnlocked.push("hold_stock_30d");

  if (newlyUnlocked.length > 0) {
    await unlock(adminClient, userId, newlyUnlocked);
  }
  return newlyUnlocked;
}
```

```ts
import { NextResponse } from "next/server";
import { createClient } from "@/lib/supabase/server";
import { ACHIEVEMENTS } from "@/lib/achievements";

export async function GET() {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const { data: unlockedRows } = await supabase
    .from("user_achievements")
    .select("achievement_key, unlocked_at")
    .eq("user_id", user.id);
  const unlockedMap = new Map((unlockedRows ?? []).map((r: any) => [r.achievement_key, r.unlocked_at]));

  const achievements = ACHIEVEMENTS.map((a) => ({
    ...a,
    unlocked: unlockedMap.has(a.key),
    unlocked_at: unlockedMap.get(a.key) ?? null,
  }));

  return NextResponse.json({ achievements });
}
```

### Task 16: Net worth snapshots API + milestone query

**Files:**
- Create: `src/app/api/portfolio/snapshots/route.ts`

- [ ] **Step 1: Create `GET /api/portfolio/snapshots`**

```ts
import { NextRequest, NextResponse } from "next/server";
import { createClient } from "@/lib/supabase/server";
import { createAdminClient } from "@/lib/supabase/admin";

const RANGES = { "1w": 7, "1m": 30, "3m": 90, "1y": 365, all: 0 };

export async function GET(request: NextRequest) {
  const supabase = await createClient();
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const range = new URL(request.url).searchParams.get("range") ?? "1m";
  const days = RANGES[range as keyof typeof RANGES] ?? 30;

  let query = supabase
    .from("portfolio_snapshots")
    .select("snapshot_at, total_value")
    .eq("user_id", user.id)
    .order("snapshot_at", { ascending: true });
  if (days > 0) {
    const since = new Date(Date.now() - days * 24 * 60 * 60 * 1000).toISOString().slice(0, 10);
    query = query.gte("snapshot_at", since);
  }
  const { data: snapshots } = await query;

  // Query milestone unlocks for the user (admin client — RLS blocks user_achievements reads? actually owner can read)
  // Actually user_achievements has owner READ RLS, so we can use the regular client:
  const { data: achievements } = await supabase
    .from("user_achievements")
    .select("achievement_key, unlocked_at")
    .eq("user_id", user.id)
    .in("achievement_key", ["net_worth_15k", "net_worth_25k", "net_worth_50k", "net_worth_100k", "net_worth_250k"]);

  const milestones = (achievements ?? []).map((a: any) => {
    const threshold = parseInt(a.achievement_key.replace("net_worth_", "").replace("k", "")) * 1000;
    return { date: a.unlocked_at.slice(0, 10), threshold, label: `$${threshold / 1000}K reached` };
  });

  return NextResponse.json({ snapshots: snapshots ?? [], milestones });
}
```
